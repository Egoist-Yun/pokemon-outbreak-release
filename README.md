# Pokémon: Outbreak (포켓몬스터 아웃브레이크)

평소와 다르게 초대량발생하는 야생 포켓몬들. 그리고 조사 지역 곳곳에서 관측되는 수상한 반응.

오박사의 의뢰를 받아 포켓몬과 함께 조사에 나서보세요.


몰려오는 야생 포켓몬들 사이에서 살아남으며 포켓몬들을 성장·진화시키고, 각 지역에서 벌어지는 사건의 실마리를 밝혀보세요.

다양한 기술과 도구의 조합으로 성장의 한계에 도전하는 Vampire Survivors 스타일의 생존 액션 팬게임입니다.


## 플레이 방법

🌐 [웹에서 바로 플레이](https://pokemonoutbreak.com/)

| 플랫폼 | 실행 방법 |
|---|---|
| 웹 | 별도 설치 없이 브라우저에서 플레이 |
| Windows | Releases에서 최신 EXE를 다운로드한 뒤 실행 |
| Android | Releases에서 최신 APK를 다운로드한 뒤 설치 |


## 세이브 파일

- Windows 저장 폴더:
`%APPDATA%\Pokemon Outbreak`

- 모바일 apk 저장 폴더 :
앱 내부에 자동 저장됩니다. 세이브 내보내기로 파일을 내보낼 수 있습니다

- 웹 버전 저장 폴더 :
해당 기기의 브라우저 내부 저장소에 자동 저장됩니다. 게임의 ‘세이브 내보내기’로 세이브 파일을 다운로드할 수 있습니다.

- 저장 파일:
`pokemon_outbreak_godot.json`

업데이트 전에는 안전하게 세이브 내보내기로 저장 데이터를 백업해주세요.
저장 데이터는 웹·Windows·Android 사이에서 자동으로 동기화되지 않습니다.
다른 기기나 플랫폼으로 옮길 때는 게임의 세이브 내보내기·불러오기 기능을 사용하세요.

## 업데이트 방법

- 웹: 페이지를 새로고침하면 최신 버전을 불러옵니다.
- Windows: 게임을 종료한 뒤 새 EXE로 교체합니다.
- Android: 기존 앱을 삭제하지 않고 새 APK를 설치합니다.

## 주요 컨텐츠

## 지역 공략과 보스 전투

지역마다 달라지는 적 구성과 전투 환경에 맞춰 팀을 구성하세요.

레벨업으로 기술을 강화하고 동료 포켓몬을 진화시키며,
고유한 공격 패턴을 사용하는 중간보스와 최종 보스에 맞서세요.

지역을 클리어하면 다음 조사 지역이 열립니다.

## 반복 도전으로 넓어지는 선택지

플레이하며 해금 조건을 달성해 새로운 캐릭터와 포켓몬, 도구를 만나보세요.

캐릭터마다 다른 능력과 시작 포켓몬,
프렌들리숍에서 구매하는 영구 강화를 활용해
이전과 다른 조합으로 다시 도전할 수 있습니다.

## 무한 생존 모드

무한 모드에서는 정해진 클리어 시간 없이
계속해서 등장하는 적들을 상대합니다.

트레이너와 포켓몬들, 도구의 조합을 시험하며
자신의 생존 기록을 갱신해보세요.

## 의견과 오류 제보
플레이 중 발견한 문제나 개선 의견은 [Issues](https://github.com/Egoist-Yun/pokemon-outbreak-release/issues)에 남겨주세요.

링크 안 페이지의 우측 상단의 New issues를 누르면 작성 가능합니다.

오류 제보에는 아래 내용을 함께 적어주시면 도움이 됩니다.

- 게임 버전과 플레이 플랫폼
- 기기 모델 또는 PC 환경
- 문제가 발생한 상황과 재현 방법
- 가능하다면 스크린샷이나 영상
